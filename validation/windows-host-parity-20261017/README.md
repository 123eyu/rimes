# Windows 宿主层级与浮动窗口修复（2026-10-17）

已本机安装 `1.1.5-win-hosts.20261017`。基线 `823c910b600c` 加当前工作区修改，
不是已提交发布版。源快照 `d417fad07181f67f32dd0298c7c2c829390817a4971e218ad48c290b2e9391ff`。

## 问题与修复

- 安装前只读检查发现：设置窗口仍可见但不在前台，Buffer（当时隐藏）的
  `WS_EX_TOPMOST` 已取消。生产代码在设置的整个生命周期内主动降级 Buffer，
  并在 `WM_WINDOWPOSCHANGING` 强制把 Buffer 排到设置后面。删除这两个策略，
  对齐 macOS 浮动、非激活 NSPanel；设置保持普通可获焦窗口，捕获权限仍独立撤销。
- Capsule 底栏原本只有 TOOLWINDOW / NOACTIVATE，没有 TOPMOST。补齐浮动角色；
  管理/编辑明确离开置顶层，返回底栏恢复；显式原生搜索只改变焦点能力，保留置顶。
- 设置核心顺序调整为输入法、外观、Buffer、Mailbox、Capsule、连接器、插件、维护；
  并击属于扩展。页面身份不因视觉顺序改变；方向键及数字导航使用视觉顺序，程序打开
  指定页也同步逻辑焦点。
- 插件管理按缓冲插件 / Capsule 插件 / Mailbox 插件 / 内置扩展分类，并为全部项目分页。
  旧官方包目录只有四项；本次接入八个已实现的宿主模块之后，不能再用固定四行展示整个目录。
  宿主模块开关与各自模块菜单复用同一状态，停用同步撤销借用输入、隐藏表面、取消对话生成；
  内置模块不暴露尚未支持的下载/卸载操作。

## 验证

- x64 / x86 编译通过；各通过 RimesSettingsUi、RimesPeripherals、RimesOfficialPlugins。
- 原生 UI 检查各 44 状态通过，覆盖浮动与非激活、底栏/编辑往返、独立搜索、普通 Mailbox、
  模块状态共享、内容布局和原有输入交互。设置另导出 109 个设置/Buffer/图标预览，
  人工查看核心分组、深浅色插件列表及筛选控件；选定图像已放在本目录。
- 设置测试覆盖开/关/快速重开设置、流式刷新、同步原生 Z-order 改动、几何变化，
  确认 Buffer 始终保留浮动与非激活属性；隐藏的 Buffer 不因设置操作显示，
  失效的输入捕获不会因置顶恢复。
- 插件分页和筛选测试核对操作的稳定身份；空分类隐藏旧按钮，底栏与设置启停状态一致。
- `git diff --check` 通过。构建仅存在原有 MSB8028 路径别名警告。

## 安装状态

`installed-result.json` 和 `post-install-check.json` 记录真实本机结果：
只有一个新版 Broker 运行，已安装 EXE 与构建哈希一致；当前 Buffer HWND 同时具有
TOPMOST 和 NOACTIVATE。安装保留设置、并击方案、词库、内容库及登录启动配置，并保存备份。

本次 x64/x86 TSF DLL 与上一个安装版本逐字节相同，界面修复在重启 Broker 后已生效，
无需注销。安装器的 `requiresSignOut=true` 是此前状态继承，不能据此断言本次界面修复
必须注销；更早进程中的首字补丁是否生效仍取决于实际宿主 DLL 版本和用户实测。

## 尚未完成的功能对等

macOS 内置扩展正式名称为“并击”“打字测速”“统计”。后两项官方包目前只声明 macOS，
Windows 尚无对应日常聚合计数、成绩存储、文章跟打和设置页实现；此次未伪造支持状态。
Capsule / Mailbox 全部功能差异继续见 `platforms/windows/native/PERIPHERALS.md`。
本次完成窗口与宿主/插件分类修正，不代表全部 macOS 功能已经移植。
