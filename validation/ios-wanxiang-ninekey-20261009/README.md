## 导入操作

1. 把 ZIP 存到 iPhone 的“文件”中。
2. 灵犀 App →“Rime 方案包与导入”→“从 ZIP 检查方案包”，选这个 ZIP。
3. 选“万象拼音·灵犀兼容版”并部署；九键和词库依赖自动带入。
   也可同时保留“万象九键·灵犀兼容版”这项推荐选择。
4. 部署成功后启用万象全拼。此步骤与导入分开，不会自动切换当前输入方式。
5. 在本次修复版本的“键盘布局与换肤”里选“9 键 · 全拼”，重新唤起键盘。
   可随时选“26 键”恢复全拼字母键盘。并击键位仍保留。
