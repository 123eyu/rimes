20 组实际 AppKit 与 GTK 渲染：键位方案、配置、课程、练习、学习进度 × night/day/quiet/rasta。每页宽 698 逻辑像素、缩放 2×，使用同一公开飞耀方案、相同选中映射和隔离的空进度。两端均直接捕获产品控件；按内嵌 ICC 转换到 sRGB 后计算差异，不重画参考图。

每页总尺寸、所有卡片的坐标和尺寸已逐项匹配，原始控件树读数保存在各图片的 `.geometry.json` 中。截图时关闭 GTK 动画，避免把滚动或启用控件的过渡帧误当成静态状态。

本组仍为 `requires_review`：字体字形、字重和度量、组合框箭头、分段控件、文本框边框、表格列宽/行高及滚动条仍有差异。选中、悬停、错误、加载、禁用、恢复等完整状态和真实桌面继续在 [#179](https://github.com/scholay/xsime/issues/179) 验收，不能仅凭相同卡片尺寸认定像素级对齐已完成。
