# 提案：学习词回顾扩展（每日沉淀、评分初筛、批量清理）

状态：草案，待维护者评审。2026-11-11 基于 `main`（`4678afc5`，librime 1.17.0）与一份真实 `rime_ice.userdb` 副本的实测写成；尚未实现任何代码。对应路线图 [#249](https://github.com/scholay-xsime/xsime/issues/249)。

## 目标

每天打字学到的词能被看到；错词和不该成词的短语可以由用户决定保留或删除；可选地先由 ChatGPT 模型做一轮 1–5 评分初筛，用户再定期回来维护。

不做：替换 librime 的学习机制；自动删除任何词；把词库内容默认发送到外部服务。

## 实测依据

| 事实 | 结果 |
|---|---|
| 学习词总数（`rime_ice`） | 34,784 条 |
| 只用过一次 | 18,912 条 |
| 已是删除标记（计数 ≤ 0） | 1,375 条 |
| 5 字及以上短语 | 1,311 条 |
| 导出里有没有日期 | 没有。普通导出是“词、编码、计数”；快照（`.userdb.txt`）多出 `c= d= t=`，`t` 是逻辑 tick，不是日期 |
| 批量删除是否可行 | 可行。导入计数为 `-1` 的行后，这些词从导出中消失（34,784 → 34,781） |
| 删除是否持久 | 是。备份快照里它们变成 `c=-N` 的删除标记，同步合并时不会被旧数据复活 |
| 模型调用开销 | `codex exec` 每次约 2.1–2.4 万 token 的固定开销，与词数无关；5 个测试词用时 44–65 秒 |

## 宿主

独立的内置扩展（建议 ID `builtin.lexicon-review`，显示名“词库”），带自己的设置页和开关，不并入“统计”。

- 统计扩展只记数量；本扩展保存真实词语并会删除数据，需要单独的授权开关。
- 不依赖 AI、Mailbox 或网络即可完成“查看”和“删除”，符合[系统架构](../architecture/system.md)对普通输入的要求。
- AI 初筛结果到达后通过 Mailbox 提示“本轮已评分 N 个词”，由用户明确点开处理。
- Buffer 不承载此功能。Capsule 待 [#247](https://github.com/scholay-xsime/xsime/issues/247) 定位确定后，可作为只读浏览入口。

## 设计

### 1. 每日记录

- 每天首次空闲时（以及用户手动刷新时），通过现有 `UserLexiconService` 导出当前学习词，与上一份快照比较。
- 新出现的词记为当天“新学”；计数增加的记为“再次使用”。只保存差异，放在 `~/Library/RIMES/lexicon-review/days/YYYY-MM-DD.json`。
- 首次启用时现有 3 万多条没有日期，统一归入“启用前”，按计数和长度筛选处理。
- 沿用 `KeyFrequencyStore` 的安全规则：拒绝符号链接、限制文件大小、损坏时只读并提示。

### 2. 回顾页

- 按天分组的列表：词、编码、使用次数、评分（如有）。
- 筛选：只用过一次、5 字以上、未评分、评分 ≥ N。
- 排序：默认按评分从高到低，无评分时按“新学”时间从新到旧。

### 3. 删除

- 单条删除、多选删除、“删除评分为 5 的全部”这类一键操作。
- 实现：生成计数为 `-1` 的导入文件，经 `importUserDictionary` 写入。删除前自动备份一份快照；保留最近若干份，可按轮次撤销（把该轮词以原计数重新导入）。
- 每轮删除写入本地日志：时间、条数、来源（手动 / 评分阈值）。

### 4. 评分初筛（可选，默认关闭）

- 模型只输出 1–5 的分数，不输出文字说明。5 表示最值得警惕（疑似错词或误成词），1 表示正常。
- 输出格式固定为每行 `词<TAB>分数`；解析失败或缺行的词保持“未评分”，不猜测。
- 默认模型 `gpt-6-luna`（官方文档明确用于分类类的高频任务）。模型是设置项，可改为其他 Codex 可用模型；`codex-auto-review` 实测可直接调用且评分一致，但它是隐藏模型，官方未说明这种用法是否计费或受支持，不作为默认。
- 复用 `AITextCodexAppServer` 已有的按请求指定模型与推理强度的通道，推理强度用 low。
- 因为固定开销大，按批发送：每次数百个词。一轮的上限、批大小在设置里可调。
- 隐私：评分会把个人词语发送给 OpenAI。开关默认关闭；每一轮由用户手动发起，并在发起前显示将发送的词数。可设置排除规则（例如含数字、含英文、超过某长度的不发送）。

### 5. 例行维护

- 设置页显示“未回顾 N 个词”。可选每周提醒一次。
- 不做自动删除；评分只影响排序和一键操作的范围。

## 分步交付

1. 每日记录 + 回顾页（只读）。
2. 删除、备份与撤销。
3. 评分初筛与 Mailbox 提示。
4. 例行提醒；其他平台跟进。

## 待确认

- **跨词库**：先只做 `rime_ice`，还是同时覆盖 `wubi86`、`english`。
- **编码列**：同一词可能对应多个编码（多音、简拼）。列表按“词”合并显示还是逐条显示。
- **撤销范围**：librime 对被删词是否会在再次上屏时自动恢复学习（预期会，需实测）。
- **用量**：Pro 套餐下 Luna 的额度与计费方式未能从官方定价页读到，需在首轮实测后记录。
- **平台**：导出桥目前只在 macOS；Windows、Linux、移动端需要各自的导出与导入路径。
