# 犀术IME / 犀術IME / XSIME 1.2.1

[GitHub Release](https://github.com/scholay-xsime/xsime/releases/tag/v1.2.1) 已公开 macOS、Windows、Android 和 Linux 安装包及更新清单。iOS 1.2.1 的商店构建与 Apple 审核单独进行；实际可用版本以 [App Store](https://apps.apple.com/app/id6814620242) 为准。

## 更新内容

- iOS：优化候选栏、状态栏、Buffer 插件入口和外部输入后的回车键；新增可选的实验性语音与手写输入。语音需要完全访问、麦克风及语音识别权限，并由用户主动启动；手写识别在设备上运行。
- macOS：改进候选窗口和 Buffer 定位、打字练习以及更新兼容性；官方插件固定到经过集成的源码版本。
- Linux：整合空格并击及输入法共存相关改进，继续保留用户词库和配置。
- Android：版本更新为 1.2.1，安装包使用原有长期签名。

## 下载与状态

| 平台 | 渠道 | 验证情况 |
| --- | --- | --- |
| macOS | 签名并经 Apple 公证的 PKG | 同一签名包在远端完成安装和升级检查 |
| Windows | 完整 EXE 安装器和 ZIP，支持 x64 / x86 | 两架构输入与安装器检查通过；EXE 未签名 |
| Android | APK 和 AAB，versionCode 24 | 长期签名和远端构建检查通过 |
| Linux | Ubuntu amd64 DEB 和 SHA-256 | 远端完成包安装、升级、重装和卸载检查 |
| iOS | [App Store](https://apps.apple.com/app/id6814620242) | 1.2.1 商店构建准备中，尚未提交审核；本次 GitHub Release 暂无社区 IPA |

截至 2026-11-27，Apple 页面仍显示 1.2.1 为准备提交状态。发布者报告曾在 iPhone 上使用过该功能，但没有提供与本次集成提交逐项对应的设备验收记录；iPad 不作为本次发布前提。实验性语音使用的键盘麦克风路径是否获 Apple 审核接受，须以实际审核结果为准。
