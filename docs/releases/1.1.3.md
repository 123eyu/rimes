# 灵犀输入法 1.1.3 发布准备

本轮从 main 构建 macOS、iOS、Android、Windows 和 Linux 安装包。版本目标统一为 1.1.3，Android versionCode 17，iOS 本地构建号 56；macOS 构建号由正式 CI 生成。

五端设置提供 Rime 方案导入入口，同一份标准 ZIP 无需按平台重新打包；支持带编码的 UTF-8 TXT/TSV。导入先检查与部署，再启用；失败时保留当前方案，删除导入包时保留学习数据。原始万象基础包全拼、九键及通用文本词库用于安装包验证。模型、原生扩展和其他宿主的键盘皮肤不属于统一导入范围。

Windows EXE 沿用未签名分发，包含 x64 Broker、x64/x86 TSF 与运行时。Linux 提供 Ubuntu 24.04 amd64 的 Fcitx5 DEB，随包提供隔离的固定版本 Rime/Lua。其他 Linux 发行版和真实桌面覆盖单独记录。

构建和自动导入测试不等于安装验收或公开发布。Android 手机与 Windows 测试机当前不可用，先执行自动测试；macOS 使用正式 signed-stage 安装验收，iOS 处理与审核状态从 App Store Connect 读回。最终安装包、提交、校验和和发布状态以公开 Release 为准。
