# 犀术IME / XSIME 1.1.8

状态：发布准备中，尚未公开。2026-10-22 维护者授权将 iOS 新版作为移动端对齐基准，纳入现有桌面修复，发布 GitHub Release、TestFlight 和 iOS 全球商店更新。构建和产品测试走远端 CI，备份与本地验收资料保留。

## 发行范围

- 五端：按方案读取实际可用开关，独立保存输入偏好；五笔四码唯一上屏与第五码顶字分别配置。保留原方案、外部补丁与个人数据。
- iOS：统一普通九键和 26 键底栏，优化键帽、字形与系统容器背景；普通键盘 Shift 支持一次大写、双击或长按锁定，并击保留持续大写切换。保留可选上滑、高度和数字九宫格。
- Android：对齐 iOS 普通底栏、默认宽空格、字体与平面按键反馈，支持相同 Shift 状态；显式选择的旧窄空格布局保留，表情另可从键盘选项进入。包含已合并的 TYPE_NULL 聊天输入框修复。
- macOS：Capsule 复用隐藏卡片以改善重新打开速度，Buffer 首次定位使用实际高度，设置快捷键可关闭当前窗口，权限引导集中排队。普通翻译先检查已安装语言包，下载由设置中的明确操作触发。
- Windows：包含已合并的设置页面按变化刷新、编辑状态保留及官方插件历史控件修复。
- Linux：包含本轮方案偏好和已合并修复，更新与 macOS 共享行为的契约记录。

未把尚无定位证据的 iOS 长期卡顿、Linux 共存反馈或 Windows 特定系统搜索宿主验收记为已解决；词库与短语新增功能继续暂缓。更完整的模糊音、候选显示、导入入口和云服务仍属后续计划。
