# 灵犀输入法 1.1.4

五端同步新增灵犀五笔，并完善五笔 86 的拼音查字。

- 五笔 86：`z` 引导全拼查字，候选显示括号内的五笔编码。
- 灵犀五笔：直接输入五笔码或全拼，完整五笔匹配优先，也支持 `z` 引导查字。
- 两套五笔方案支持四码唯一自动上屏，重码保留候选，拼音查字不触发此规则。
- 手机候选栏显示较小字号的编码提示，注释不随汉字上屏。
- Windows：纳入沙盒／无独立候选窗宿主的输入连接与候选协商修复，并补齐跨架构卸载后的注册验证。
- 保留各端现有第三方方案导入、学习词库和用户设置。

用法及 Linux 候选面板版本差异见[五笔输入](../wubi.md)。安装包与各平台发布状态分别记录于本次 GitHub Release 和 Apple 商店页面。
