# 犀术IME / XSIME 1.1.6

本轮统一设置内的应用更新流程，并收敛各平台与官方插件的已推送改动。

## 用户可见变化

- macOS、Windows、Android、Linux 设置提供检查更新、下载、校验和系统安装入口。重新打开应用并确认运行版本后才显示完成；取消或失败可在设置中继续处理。
- iOS 设置查询实际可用的 App Store 版本，再跳转商店下载和安装。TestFlight 测试渠道单独显示，不用 GitHub 版本冒充已上架版本。
- Android 修复并击规则在 ICU 正则替换下导致键盘初始化崩溃的问题，纳入官方插件贡献 [rimes-plugins#10](https://github.com/scholay/rimes-plugins/pull/10) 与本体 [#192](https://github.com/scholay/xsime/issues/192)。安装取消状态也会保留，不再被旧的等待提示覆盖。
- Windows 调整按键响应的超时边界，保留超时取消、不重放输入和 Buffer 暂停行为；正式包继续包含 x64／x86 TSF。
- Linux 纳入原生 Mailbox 与现有 Buffer、Capsule、设置的主线改动。自动检查范围与真实桌面验收分开记录。

## 安装与升级

本版的四端安装包统一在 [v1.1.6 Release](https://github.com/scholay/xsime/releases/tag/v1.1.6) 发布。

| 平台 | 包与渠道 | 发布状态 |
|---|---|---|
| macOS | Apple Silicon／Intel 通用 PKG，Developer ID 签名、公证 | 已公开，同一签名包远端升级检查通过 |
| Windows | 完整 EXE／ZIP，x64 Windows，包含 x64／x86 TSF；EXE 未签名 | 已公开，完整安装器和 x64／x86 输入检查通过 |
| Android | APK／AAB，版本码 20，沿用长期签名 | 已公开，远端 Android 运行与更新检查通过 |
| Linux | Ubuntu 24.04 amd64／Fcitx5 DEB | 已公开，安装生命周期检查通过 |
| iOS | [App Store](https://apps.apple.com/app/id6814620242)／[TestFlight](https://testflight.apple.com/join/Kdj9RB4q) | 1.1.6 源码检查通过；签名上传等待发布凭据，尚未提交或上架 |

旧版尚未提供完整更新入口时，先从 Release 手动升级一次。安装保留现有设置、导入方案与学习记录；如系统安装器要求授权、注销或重启，请按提示完成。

四端安装包上传、读回校验后，CI 最后发布共同的 `update-manifest.json`。其平台条目记录包地址、版本、源码提交、SHA-256、大小和系统要求。iOS 的实际可安装版本以 Apple 页面为准。
