## 集中实测顺序

Windows 可在一次安装后一起验证：先退出并重新登录，确认新版本及实际加载路径；
关闭 Buffer，选择全拼，在开始菜单搜索输入 `nihao`，检查候选并按空格得到 `你好`；
再检查任务栏搜索、设置搜索与记事本。记录 Windows build、输入法版本，以及失败
发生在字母透传、无候选还是不能提交。最后切换浅色/暗色主题，检查系统输入法图标。

macOS 先在普通文本编辑器确认 Shift+?、Shift+6、Shift+!、Shift+: 随中英文和
标点选项变化，再进行真实锁屏/解锁与睡眠唤醒。词库故障按
[恢复说明](../user-dictionary-recovery.md) 先备份，不把用户数据损坏作为日常回归步骤。

Linux 在实际 Fcitx 桌面触发需要较长编译的方案部署后退出，确认 Fcitx 和部署子进程
已结束；随后重新启动，检查部署完成后候选与中文提交。容器通过不能替代此桌面验收。
